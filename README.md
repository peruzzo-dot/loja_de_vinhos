# 🍷 Aroma & Tanino - E-commerce de Vinhos

Este é um projeto de e-commerce focado na experiência de seleção e compra de vinhos finos. O objetivo é criar uma interface intuitiva, elegante e funcional, simulando um ambiente real de vendas online.

## 🚀 Funcionalidades Implementadas
* **Vitrine Interativa:** Exibição de produtos com cards estilizados e botões de ação rápida.
* **Cálculo de Frete:** Lógica implementada para simular prazos e valores de entrega baseados no CEP.
* **Fluxo de Checkout:** Interface de finalização de compra com seleção de métodos de pagamento (PIX e Cartão de Crédito).
* **Navegação Dinâmica:** Menu funcional com ancoragem para diferentes seções (Tintos, Brancos, Contato).

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização personalizada, uso de Google Fonts e layouts responsivos.
* **JavaScript (em progresso):** Manipulação de DOM para cálculos de frete e interatividade.
